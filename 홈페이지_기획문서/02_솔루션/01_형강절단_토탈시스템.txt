[1] 히어로 섹션
================================================================================

● 솔루션명
  "플라즈마 / 레이저 형강 절단 토탈 시스템"

● 메인 헤드라인
  "소재 투입부터 배출까지, 형강 가공의 완전 자동화(Full Automation)를 구축."

● 서브 헤드라인
  "2D(Flat Bar)부터 3D(H-Beam·파이프·앵글·부등변앵글)형상 자재까지, 
   설계 도면 기준으로 원스톱 절단 자동화를 제공합니다. 
   Laser / Plasma 두 가지 절단 에너지 옵션을 보유하고, 
   현장에 맞는 최적 구성을 제안합니다."

● 핵심 혜택 (Benefits)
  1. One-Stop 자동화: 인입 → 정렬/보정 → 절단 → 배출/잔재 처리까지 자동화 구축
  2. 2D+3D 통합 대응: 다양한 형강 소재/형상에 대한 적용 범위 확장
  3. 정밀 보정 기반 절단: 실 자재의 휨/비틀림 등을 센싱 기술로 감지하여 기준점을 보정
  4. 현장 검증 레퍼런스: HD현대중공업, 한화오션 등 대기업 납품 및 운용 경험 기반

● 미디어
  - 형강 절단 로봇 데모 영상 (자동 재생)

● CTA 버튼
  [현장 적용 상담 받기] → /contact 페이지로 이동

● 섹션 제목: "핵심 기능"
● 섹션 설명: "Smart Cutting System의 차별화된 기술력"

● 6가지 핵심 기능

1. One-Stop 자동화
   - 아이콘: ⚡
   - 설명: 인입 → 정렬/보정 → 절단 → 배출/잔재 처리까지 무인 흐름 설계

2. 정밀 보정 절단
   - 아이콘: 🎯
   - 설명: 휨/비틀림 등 비정형 변수를 반영해 기준점을 보정합니다

3. Auto-Nesting
   - 아이콘: 🔄
   - 설명: 자재 손실을 줄이도록 절단 계획을 자동 최적화합니다

4. Laser / Plasma
   - 아이콘: ⚙️
   - 설명: 두 가지 절단 에너지 옵션으로 현장에 맞는 구성 제안

5. 안전 설계
   - 아이콘: 🛡️
   - 설명: 무인 운영 환경에 맞춘 안전 인터락 시스템 적용

6. 운영 데이터
   - 아이콘: 📊
   - 설명: 절단 품질/효율 데이터를 실시간으로 모니터링
